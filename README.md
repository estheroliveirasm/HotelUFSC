# HotelUFSC
HotelUFSC é um sistema desktop em C++17 e Qt Widgets para cadastrar hóspedes e gerenciar hospedagens. Faça check-in, escolha quartos disponíveis, defina a duração da estadia e adicione serviços extras com cálculo automático do total. Consulte reservas, veja detalhes e finalize o checkout com confirmação. Os dados ficam salvos localmente em arquivo.
